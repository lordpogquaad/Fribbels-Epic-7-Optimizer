# Fribbels Epic 7 장비 최적화 도구

이것은 Epic 7의 장비를 정리하고 유닛 빌드를 최적화하는 도구입니다. 게임 내에서 최적의 장비 조합을 찾는 것은 시간이 많이 걸리고 쉽지 않기 때문에, 장비 구성 과정을 더 쉽게 만들기 위해 제작되었습니다.

사용 방법은 [**시작하기**](https://github.com/fribbels/Fribbels-Epic-7-Optimizer#getting-started) 섹션을 참조하세요.

주요 기능:

- 게임에서 장비 및 영웅 자동 가져오기
- 메인 스탯/서브 스탯/세트 등으로 장비 최적화 필터링
- 새 영웅 데이터 자동 업데이트
- 각인/유물/전용 장비 보너스 스탯 지원
- 장비 서브 스탯 효율 점수
- 강화 스탯 예측 및 편집
- 색상 코딩 결과 정렬
- 서브 스탯 보정 최적화

현재 모습:

![](https://i.imgur.com/vQ3tnol.png)

## 요구 사항

- 64비트 Windows 또는 MacOS
- Java 8 이상, 64비트 설치 필요 (없으시면 다운로드: https://java.com/en/download/manual.jsp. Windows의 경우 'Windows Offline (64-bit)' 설치 파일 사용)

## 최적화 탭

여기서는 탱커 Ruele 빌드를 예시로 최적화 탭의 각 부분을 설명합니다. 필터링을 위한 여러 패널이 있으며 각각 자세히 안내드립니다.

---

### 설정 패널

![](https://i.imgur.com/eIWkJ09.png)

이 패널은 다른 패널들이 사용할 설정을 관리합니다.

- **영웅**: 드롭다운에서 최적화할 영웅을 선택합니다.
    - **시작**: 최적화 요청을 시작합니다.
    - **필터**: 최적화가 완료된 후 클릭하면, 필터 패널의 스탯으로 결과를 필터링합니다.
    - **취소**: 진행 중인 최적화 요청을 중단합니다.
    - **설정 불러오기**: 해당 영웅의 마지막 검색 설정을 불러옵니다.
    - **설정 초기화**: 모든 최적화 설정을 기본값으로 초기화합니다.
- **스탯**: 왼쪽에는 영웅의 현재 스탯, 오른쪽에는 새 스탯을 미리 볼 수 있습니다.
- **옵션**: 영웅 최적화 옵션을 변경합니다.
    - **강화 스탯 사용**: +15 레벨 85 장비의 강화 스탯을 예측하여 검색에 사용합니다.
    - **서브 스탯 보정 사용**: 서브 스탯 보정석을 사용하여 최적화를 실행합니다. 사용 전에 영웅 탭에서 각 영웅의 최적화 설정을 먼저 선택해야 합니다.
    - **최대 강화 장비만**: 체크 시, 추가 강화/강화가 불가능한 +15 장비만 사용합니다.
    - **잠긴 아이템**: 체크 시, 잠긴 아이템을 최적화에 사용합니다. 해제 시, 잠긴 아이템은 무시됩니다.
    - **장착 아이템**: 체크 시, 장착된 아이템을 최적화에 사용합니다. 해제 시, 해당 유닛 자신의 장착 아이템을 제외한 나머지 장착 아이템은 무시됩니다.
    - **현재 유지**: 체크 시, 유닛이 현재 장착한 장비를 강제로 유지하며, 비어 있는 슬롯만 최적화합니다.
    - **장착 제외**: 최적화 검색에서 제외할 영웅의 장비를 선택합니다. 완성된 영웅을 이 목록에 추가하면 다른 영웅이 그 장비를 가져가지 않습니다. '장착 아이템'이 체크된 경우에만 적용됩니다.

---

### 스탯 필터

![](https://i.imgur.com/9VPlYjo.png)

이 패널은 최적화 결과를 필터링할 스탯을 정의합니다. 왼쪽 칸은 최솟값(포함), 오른쪽 칸은 최댓값(포함)입니다. 이 예시에서는 다음 조건의 빌드를 찾습니다:

- HP 최소 20,000
- 방어력 최소 2,400
- 속도 180 ~ 200

제출 클릭 후 최적화 결과에 필터가 적용됩니다. 결과 생성 후 숫자를 변경하고 **필터** 버튼을 클릭하여 더 엄격한 필터를 적용할 수 있습니다. 이렇게 하면 재검색 없이 결과를 좁힐 수 있습니다.

---

### 등급 필터

![](https://i.imgur.com/VvNA4ca.png)

이 패널은 기본 스탯 패널과 유사하지만 계산된 스탯에 적용됩니다. 인게임에서는 볼 수 없지만 빌드를 결정하는 데 도움이 되는 다양한 등급입니다.

- **HpS** -- `HP × 속도` 등급. 속도와 순수 HP의 조합을 원하는 유닛 최적화에 유용합니다.
- **Ehp** -- 유효 HP, 계산식: `HP × (방어력/300 + 1)`. 유닛이 죽기 전까지 받을 수 있는 피해량을 나타내며 탱킹 능력을 측정하는 데 유용합니다.
- **EhpS** -- `유효 HP × 속도` 등급. 속도와 HP/방어력 탱킹 조합을 원하는 유닛 최적화에 유용합니다.
- **Dmg** -- 평균 피해, 계산식: `공격력 × 치명타 확률 × 치명타 피해`. 유닛이 평균적으로 입히는 피해량을 측정합니다. 치명타 확률이 낮으면 치명타 발동이 적어 평균 출력이 낮아집니다.
- **DmgS** -- DPS 등급, 계산식: `공격력 × 치명타 확률 × 치명타 피해 × 속도`. 유닛이 얼마나 빠르게 피해를 입힐 수 있는지 측정합니다.
- **Mcd** -- 최대 치명타 피해, 계산식: `공격력 × 치명타 피해`. Dmg와 달리 치명타 확률을 고려하지 않으며 100% 치명타 확률을 가정합니다. 치명타 확률이 50%만 필요한 CDom 같은 유닛이나 속성 유리로 85%만 필요한 PVE 유닛의 피해 측정에 유용합니다.
- **McdS** -- 최대 DPS 등급, 계산식: `공격력 × 치명타 피해 × 속도`. 치명타 확률을 제외한 DmgS와 유사합니다.
- **DmgH** -- 브루저 등급, 계산식: `HP × 치명타 피해`. HP 스케일링 브루저에 유용합니다.
- **CP** -- 인게임 유닛 스탯 페이지에서 볼 수 있는 CP (스킬 강화 미적용). 남은 장비로 월드 보스용 미사용 캐릭터 최적화에 유용합니다.

### 서브 스탯 우선순위 필터

![](https://i.imgur.com/w55RbpG.png)

**아마도 가장 유용한 필터이지만 사용 전에 꼭 읽어보세요. 잘못 사용하면 좋은 결과가 검색에서 제외될 수 있습니다.**

각 서브 스탯 유형에 -1~3의 우선순위를 지정합니다. 모든 장비를 확인하여 각 스탯의 최대 롤 횟수를 계산하고, 롤 횟수에 선택한 스탯 우선순위를 곱합니다. 장비의 모든 스탯 점수를 합산하여 가장 높은 서브 스탯 점수 순으로 정렬합니다.

이 예시에서는 빠르고 탱킹력이 높은 Ruele를 찾으므로 다음과 같이 지정합니다:

- HP와 방어력은 최우선 순위인 3 (가장 중요한 스탯)
- 속도는 약간 낮은 2
- 저항은 1 (있으면 좋고 여전히 유용함)
- 공격력/치명타 확률/치명타 피해/효과 적중은 크게 중요하지 않으므로 0으로 설정

상위 % 슬라이더를 30%로 설정합니다. 이렇게 하면 위에서 정의한 우선순위에 따라 모든 무기를 점수 매기고, 상위 30%만 최적화에 사용합니다. 투구, 갑옷 등에도 동일하게 적용한 후 상위 30% 장비로 조합을 생성합니다.

**이 필터가 작동하려면 상위 % 슬라이더가 100% 이외의 값으로 설정되어야 합니다.** 그렇지 않으면 상위 100%의 장비를 모두 사용하게 되어 아무것도 필터링되지 않습니다. 이 등급은 휴리스틱이므로 비율이 너무 낮으면 최적 결과가 나오지 않을 수 있습니다. 30~50%가 적당하며, 50%는 관련 없는 장비(탱커 빌드에 딜 스탯 등)를 대부분 걸러냅니다. 30% 미만은 필터가 매우 민감해져 일부 유용한 장비가 제외되어 결과가 불완전할 수 있습니다. 다양한 상위 % 값을 시도해 보세요.

공격 유닛 Arby의 경우 공격 스탯만 원한다면 이런 우선순위 필터를 사용할 수 있습니다:

![](https://i.imgur.com/iy4A8d2.png)

탱킹, 피해, 효과 적중을 원하지만 저항은 원하지 않는 탱커 Champion Zerato의 경우, 저항 서브 스탯이 있으면 장비 등급을 낮추도록 저항을 -1로 설정할 수 있습니다:

![](https://i.imgur.com/idsnxVW.png)

좋은 우선순위 필터를 선택하면 관련 없거나 낮게 롤된 장비를 고려하지 않아도 되므로 최적화가 훨씬 쉬워집니다.

### 메인 스탯 및 세트 필터

![](https://i.imgur.com/NPsmTVw.png)

상당히 직관적입니다. 다음을 찾습니다:

- HP% 또는 방어력%의 목걸이
- HP% 또는 방어력%의 반지
- 속도 신발
- 속도 세트
- 저항 세트 또는 면역 세트

탱킹/공격 ML 켄처럼 세트가 크게 중요하지 않은 경우 파괴 세트도 허용됩니다. 면역 세트만 필요하고 다른 세트는 상관없다면 나머지는 비워 둡니다.

![](https://i.imgur.com/zDcMb1A.png)

### 최적화 결과

![](https://i.imgur.com/qxzV1HS.png)

여기서 최적화 결과를 확인하고, 스탯으로 정렬하며, 장비를 장착/잠금할 수 있습니다.

- 상단 행에는 현재 장착된 장비 스탯이 표시됩니다.
- 각 열은 해당 페이지의 스탯 최소/최대 범위에 따라 색상이 구분됩니다.
- 하단 화살표로 여러 페이지의 결과를 탐색할 수 있습니다.
- 모두 선택/모두 해제는 각 장비의 작은 체크박스를 수정하거나 개별 박스를 클릭할 수 있습니다.
- 선택 장착은 체크된 장비를 영웅에게 장착합니다(기존 장착 장비는 해제됨).
- 선택 잠금은 체크된 장비를 잠금 표시합니다. 설정에서 '잠긴 아이템'이 해제된 이후 최적화에 영향을 줍니다.
- 연필/망치 아이콘을 클릭하면 아이템 스탯을 편집/강화할 수 있습니다.

## 장비 탭

![](https://i.imgur.com/hEjsPOJ.png)

모든 장비 목록을 확인하고 정렬/필터링할 수 있습니다. 하단 아이콘으로 세트 및 장비 슬롯 필터를 활성화하며, X 버튼으로 필터를 초기화합니다.

### 장비 점수

**점수** 열은 WSS와 유사하지만 WSS가 무시하는 고정 스탯도 고려하는 자체 제작 스탯입니다. 계산식:

    Score = Attack %
    + Defense %
    + Hp %
    + Effectiveness
    + Effect Resistance
    + Speed * (8/4)
    + Crit Damage * (8/7)
    + Crit Chance * (8/5)
    + Flat Attack * 3.46 / 39
    + Flat Defense * 4.99 / 31
    + Flat Hp * 3.09 / 174

레벨 85 장비의 최대 롤(속도는 5가 아닌 4 최대)을 기준으로 장비가 얼마나 잘 롤되었는지 측정합니다. 고정 스탯의 평균 롤을 계산하고 최대 레벨 기본 5성 유닛의 평균 스탯과 비교하여 고정 스탯 롤 품질을 측정했습니다. (예: 평균 고정 방어력 롤은 31이며, 평균 유닛의 방어력 4.99%에 해당합니다)

이 페이지의 다른 점수는 다음과 같이 정의됩니다:

- dScore - 딜 점수. 공격력/%, 치명타 확률, 치명타 피해, 속도만 계산하는 점수 공식
- sScore - 지원 점수. HP/%, 방어력/%, 효과 저항, 속도만 계산하는 점수 공식
- cScore - 전투 점수. 효과 적중과 효과 저항을 제외한 점수 공식

### 서브 스탯 보정 옵션

**서브 스탯 보정 추가** 버튼으로 서브 스탯 보정을 사용하여 최적화할 때 영웅 설정을 커스터마이즈할 수 있습니다.

![](https://i.imgur.com/wxUsDWI.png)

서브 스탯 선택 메뉴에서 _변경 안 함_ 열에서 _원하는 스탯_ 또는 _원하지 않는 스탯_으로 서브 스탯을 드래그할 수 있습니다. 원하지 않는 서브 스탯은 원하는 서브 스탯으로 변환되며, 변경 안 함은 수정되거나 결과에서 선택되지 않습니다.

- **옵션**
    - 롤 제한 - 교체할 최대 롤 수를 선택합니다. 예를 들어, 롤 제한 = 1은 강화되지 않은 기본 스탯만 교체합니다. 일반적으로 2개 이상의 롤을 교체하는 것은 좋지 않으며, 숫자가 높을수록 더 많은 조합이 생성됩니다.
    - 보정 등급 - 상급 또는 하급 젬 스탯 사용 여부를 선택합니다.
    - 롤 품질 - 수정된 서브 스탯의 롤 값을 최소 롤에서 최대 롤까지 선택합니다. 실제 인게임 값은 랜덤입니다. 값은 가장 가까운 정수로 반올림됩니다.
    - 원하는 스탯 - 최적화 시 원하는 스탯을 원하는 스탯으로 교체할 수 있는지 여부를 선택합니다. 예를 들어, 허용 시 최소 속도 롤을 최대 속도 롤로 교체할 수 있습니다. 허용하지 않을 경우 속도는 수정되지 않습니다.

* **서브 스탯 보정 사용 팁**
    - 각 서브 스탯 변경은 새 아이템으로 간주되므로 상위 %를 높이고 좋은 결과를 위해 더 기다려야 합니다.
    - 더 적은 "원하는 서브 스탯"과 "원하지 않는 서브 스탯"을 선택하면 조합이 줄어들어 최적화가 빨라집니다.
    - 서브 스탯 보정 활성화 시 수십억 개의 조합을 검색하는 것은 드문 일이 아닙니다. 아이템 잠금 및 영웅 우선순위 필터 사용으로 검색 공간을 줄일 수 있습니다.
    - 최적화 도구는 보정 가능성을 보여주기 위한 것이지만, 특정 빌드를 위해 특정 아이템을 수정하는 것이 항상 좋은 것은 아닙니다. 신중하게 선택하세요.
    - 각 서브 스탯 변경은 업그레이드로 간주되며, 예를 들어 1~2개의 아이템만 수정하고 싶다면 "Upg" 필터로 필터링할 수 있습니다.\*\*

### 자동 가져오기 설정

자동 가져오기 기능을 사용하려면 다음 추가 단계가 필요합니다:

##### Windows에서 자동 가져오기 최초 설정

단계별 영상 가이드: https://youtu.be/bDjP5eiOfK0?t=182

1. Windows 설치 파일(64비트)을 사용하여 [Python 3.4+](https://www.python.org/downloads/release/python-392/)를 설치합니다. [3.9.2 직접 다운로드 링크](https://www.python.org/ftp/python/3.9.2/python-3.9.2-amd64.exe). **중요: Python을 PATH에 추가하는 옵션을 활성화하세요.**
2. Windows용 [Npcap](https://nmap.org/npcap/#download)를 설치합니다. [직접 다운로드 링크](https://nmap.org/npcap/dist/npcap-1.31.exe). 설치 중 "무선 어댑터에 대한 원시 802.11 트래픽(및 모니터 모드) 지원" 설정을 활성화하세요.
3. 컴퓨터를 재시작합니다.

##### Mac에서 자동 가져오기 최초 설정

1. [Python 3.4+](https://www.python.org/downloads/release/python-392/)를 설치합니다. python3를 기본값으로 설정하는 추가 단계가 필요합니다. pyenv 사용 권장 (https://opensource.com/article/19/5/python-3-default-mac)
2. [Wireshark](https://www.wireshark.org/download.html)를 설치합니다.
3. Wireshark 설치 중 ChmodBPF.pkg도 설치합니다: [이미지 참조](https://i.imgur.com/FqV0BA5.png)
4. 컴퓨터를 재시작합니다.

### 자동 가져오기 사용

Google Play 게임즈 베타, 에뮬레이터, 스마트폰 또는 M1+ 칩 맥북에서 자동 가져오기를 사용할 수 있습니다.

##### Google Play 게임즈 베타 / 에뮬레이터 / M1+ 맥북에서 자동 가져오기 실행

단계별 영상 가이드: https://youtu.be/bDjP5eiOfK0?t=357

1. 위의 요구 사항 지침에서 필요한 프로그램을 설치합니다.
2. 에뮬레이터를 열어 두고 에픽 세븐을 종료합니다.
3. 스캔 시작을 클릭합니다.
4. 에픽 세븐을 열고 로비에 접속합니다.
5. 스캔 중지를 클릭합니다.
6. 최대 30초 기다린 후 데이터가 나타나면 내보내기를 클릭하여 "gear.txt"로 저장합니다.
7. 가져오기 탭의 병합 버튼으로 "gear.txt"를 가져옵니다.
8. 장비 탭으로 이동하여 레벨 = 0 필터를 사용해 레벨 0 아이템을 수동으로 수정합니다.

##### 스마트폰에서 자동 가져오기 실행

1. Windows 10에서 모바일 핫스팟 설정을 활성화합니다: [이미지 참조](https://i.imgur.com/89o8NfG.png)
2. Mac에서 환경설정의 인터넷 공유를 활성화합니다. (하드웨어에 따라 일부 기기에서 사용 불가)
3. 스마트폰에서 모바일 핫스팟에 연결합니다. (컴퓨터가 핫스팟을 제공하고 스마트폰이 컴퓨터 핫스팟에 연결해야 합니다)
4. 에뮬레이터 대신 스마트폰을 사용하여 이전 '에뮬레이터에서 자동 가져오기 실행' 섹션의 3~8단계를 따릅니다.

### 유닛 최적화

1. 영웅 탭에서 이름을 선택하고 새 영웅 추가를 클릭하여 유닛을 추가합니다.
2. 새 영웅을 선택하고 보너스 스탯 추가를 클릭합니다. 여기에서 유물, 각인 또는 전용 장비의 스탯을 추가합니다. [예시](https://i.imgur.com/2aC22mN.png)
3. 최적화 탭으로 이동하여 영웅을 선택합니다. 오른쪽 패널에 원하는 메인 스탯과 세트를 입력합니다. [예시](https://i.imgur.com/3yfbkrE.png)
4. 원하는 필터를 입력합니다. 각 필터는 이 섹션에 자세히 설명되어 있습니다: https://github.com/fribbels/Fribbels-Epic-7-Optimizer#optimizer-tab
5. 제출을 클릭하면 처리 후 결과 테이블이 표시됩니다.
6. 화살표 키 또는 마우스로 결과를 탐색하고, 원하는 결과를 선택한 후 선택 장착을 클릭합니다.
7. 이제 영웅이 해당 장비를 착용하게 됩니다.
8. 특정 아이템을 유닛에 수동으로 장착하려면 장비 탭 -> 선택 아이템 편집 -> 장착으로 이동합니다. [예시](https://i.imgur.com/Bqs3ETL.png)

### 좋은 최적화 결과를 위한 팁

최적의 결과를 얻기 위한 빠른 팁입니다. [최적화 패널](https://github.com/fribbels/Fribbels-Epic-7-Optimizer#optimizer-tab) 설명을 읽었다고 가정합니다.

- **가능하면 세트와 메인 스탯을 입력하세요.** 결과를 좁히는 가장 쉬운 방법입니다.
- **서브 스탯 우선순위 필터를 사용하고 스탯 우선순위를 올바르게 설정하세요!**
    - 딜러 유닛은 공격력/치명타 확률/치명타 피해/속도 등에 높은 우선순위를 두어야 합니다.
    - 탱커 유닛은 HP/방어력/속도 등에 높은 우선순위를 두어야 합니다.
    - 잘못된 우선순위는 좋은 옵션이 필터링되어 나쁜 결과를 초래합니다.
- **검색 속도를 높이려면 상위 %를 낮추고, 더 많은 결과를 검색하려면 높이세요.** 대부분의 경우 20~30%를 사용하며, 최고의 장비만 사용하고 싶다면 더 낮게 설정합니다.
- 특정 장비를 영웅에게 유지하고 싶다면 장비 탭 -> 선택 아이템 편집 -> 장착으로 먼저 장착합니다. [예시](https://i.imgur.com/oNO9ivL.png) 그런 다음 "현재 유지" 체크 상태로 최적화 도구를 사용하면 해당 장비가 유지됩니다.

## 문제 해결

### 자동 가져오기 문제 해결

- 30초 이상 걸리거나 오류가 표시되지 않는 경우:
    - 요구 사항이 설치되어 있는지 확인하세요(Windows는 Python과 Npcap, Mac은 Python과 Wireshark). 재설치를 시도해 보세요.
    - 컴퓨터를 재시작하세요.
- 오류가 표시되는 경우:
    - 몇 번 더 시도해 보세요. 가끔 실패하는 경우가 있습니다.
    - VPN을 사용 중이라면 비활성화하거나 암호화를 UDP로 변경하세요.
    - Hyper-V가 활성화된 경우:
        - Hyper-V가 없는 기기에서 가져오기를 시도하세요.
        - 네트워크 연결 보기 메뉴를 열고 Hyper-V Bluestacks 네트워크 어댑터를 비활성화한 후 모바일 핫스팟 가져오기 옵션을 사용하세요.
        - 또는 스캐너 코드를 수정하여 네트워크 인터페이스를 하드코딩하세요: https://github.com/fribbels/Fribbels-Epic-7-Optimizer/issues/50#issuecomment-804275567

### 최적화 도구 문제 해결

- Java 관련 문제가 발생하는 경우:
    - Java 8 - 64비트가 설치되어 있는지 확인하세요.
    - Java가 경로 환경 변수에 있는지 확인하세요: https://mkyong.com/java/how-to-set-java_home-on-windows-10/
    - 컴퓨터를 재시작하고 앱을 다시 열어보세요 (이전 하위 프로세스가 실행 중일 수 있습니다).

- 다운로드 후 앱 실행에 문제가 있는 경우:
    - 설치 프로그램 대신 소스 코드를 다운로드했을 수 있습니다. https://github.com/fribbels/Fribbels-Epic-7-Optimizer/releases 에서 'FribbelsE7Optimizer-Setup-1.x.x.exe' 파일을 클릭하세요 (Mac은 dmg 파일). 소스 코드가 아닙니다.

- 가져오기 중 "Error: EPERM: operation not permitted" 오류가 발생하는 경우:
    - 특히 Java를 최근에 설치한 경우 컴퓨터를 재시작하세요.
    - 바이러스 백신 프로그램이 앱을 차단할 수 있습니다. 일시적으로 비활성화해 보세요. Avast와 관련된 문제가 보고되었으며 Avast를 일시적으로 비활성화하면 해결됩니다.
    - 파일 또는 폴더 내용이 압축되어 있을 수 있습니다. 폴더의 이 박스를 해제하세요: https://i.imgur.com/kSzTqek.png
    - 앱을 관리자로 실행하세요.
    - 앱 폴더를 새 파일 위치로 이동하세요.
    - Windows 보안 랜섬웨어 방지를 비활성화하세요: https://www.majorgeeks.com/content/page/how_to_enable_or_disable_windows_defender_exploit_guard_controlled_folder_access.html

- "Current relative path is C:\Windows\system32..." 오류가 발생하는 경우:
    - 원인은 정확히 알 수 없지만 data/tessdata/eng.traineddata/eng.traineddata 파일을 오류에 표시된 system32 경로에 복사하면 해결됩니다.

- Mac에서 "The application "FribbelsE7Optimizer" can't be opened" 문제가 발생하는 경우:
    - 앱을 우클릭하고 메뉴에서 열기를 클릭하세요.
    - Archive Utility 대신 앱 스토어의 Unarchiver로 파일을 압축 해제해 보세요. [예시](https://i.imgur.com/y9uGQcH.png)

- 동일한 스탯을 가진 최적화 결과 행이 많이 보이는 경우 중복 장비가 있을 가능성이 높습니다. [예시](https://i.imgur.com/hUcyN1I.png)
    - 장비 화면의 중복 필터를 사용하여 중복 장비를 찾아 수정하세요. 또는 장비 데이터를 덮어쓰기/병합하여 처음부터 시작하세요. 추가 옵션을 사용하면 중복 장비가 추가될 수 있으므로 주의하세요. 대부분의 경우 병합을 사용하는 것이 좋습니다.
